# 执行任务与验收清单

状态：原始验收清单保留；已实施核心工程。逐项完成/部分完成/未执行状态及验证记录见 [IMPLEMENTATION_RESULTS](IMPLEMENTATION_RESULTS.md)。未勾选项不能据此宣称全部未动工，也不能依据代码存在宣称完整验收。基线见 [README](README.md)。

## 使用方式

每个任务提交时填写负责人、commit、测试命令、结果、失败样本和证据产物路径。建议一个任务一个可回退提交；保留旧记录，只新增带版本的转换/推理结果。阻塞项未解决时，相关结论保持待复核。

## 第一阶段：可信输入与证据（阻塞后续自动发布）

- [ ] T01：追踪真实执行入口，记录 API/worker/workflow 到 EvaluationPipeline 的调用图；以端到端测试证明新模块进入真实路径，不能只新增未调用 schema。
- [ ] T02：ICC、EXIF、帧选择与传递函数记录；构造带配置文件和旋转的夹具，验证已知色值和像素方向。未知配置不能静默按 sRGB 冒充已知。
- [ ] T03：多脸实例与原生 ROI；合成人工夹具及许可样张覆盖前后排、边缘、遮挡、无人脸、检测漏检；漏检可人工补框且版本可追踪。
- [ ] T04：结论结构化比较，区分属性、区域、方向、程度和条件；相同来源同维度但相反方向必须进入冲突，不能算一致。
- [ ] T05：删除固定 objective_support=1 的无证据支持；每项支持绑定公式、数据、阈值和适用条件，无法支持时为 unknown。
- [ ] T06：支持与反例共同裁决；测试“3 个支持、21 个相反”、同一环境重复、强反例、全 unknown，确保不能自动确认为普遍规律。
- [ ] T07：外部证据按来源/主张/版本关联；两个设备相同结论文本不能交叉注入外部背书。匹配主键不依赖自由文本。

第一阶段门槛：所有上述失败夹具转为正确处理，旧端到端链路仍可运行；状态缺失/争议时禁止自动升级为确认。

## 第二阶段：专业报告与可审计总结

- [ ] T08：建立 scene_family、六类主挑战及辅助标签；人工可审核。输出亮暗不得单独决定采集照度类型。
- [ ] T09：建立属性级可比性；已确认配对但取景不同不能整组误判为“未匹配”，也不能直接算像素级差异。
- [ ] T10：建立 claim-evidence 表，保存支持、反例、独立场景家族数和完整分母；每条正文判断有原图/裁剪定位入口。
- [ ] T11：画像由已裁决主张合成，至少包括优先目标、优势、代价、失败条件、反例；证据不足输出不足，而非通用品牌标签。
- [ ] T12：报告重构为结论摘要、前摄难点、挑战矩阵、场景分析、来源画像、技术假说、完整附录。
- [ ] T13：统一分析结构与 HTML/DOCX 字段契约，测试实际非空内容；失败不悄悄换成套话。验证所有图、锚点、来源和缺失说明。
- [ ] T14：对 Camera0717 做记录适配回放，全量覆盖 143 资产/24 对应位置；每项观察保留旧 ID 与版本，不把新裁决覆盖为原始判断。
- [ ] T15：独立人工审查主要结论、相反案例与高风险建议；记录审阅者、分歧、修改和仍不确定项。模型独立复核不能冒充人审。

第二阶段门槛：正文所有结论可追溯；读者只看首尾即可理解主要发现和范围；附录覆盖完整；人工复核未完成时发布为“模型辅助观察报告”，而不是已验证专家结论。

## 第三阶段：感知能力验证

- [ ] T16：冻结按 scene_family 划分的开发/校准/测试数据，冻结模型、提示词、输入条件和分析计划。
- [ ] T17：人工独立标注区域/属性/方向及不确定性，保留分歧；受控变换同时记录操作参数与人眼可见性。
- [ ] T18：运行原图成对、暗部/整体混杂、影调、颜色、镜像、顺序交换、重复、措辞与尺度测试。
- [ ] T19：报告按属性的正确/错误/弃答、完整分母和场景聚类区间，明确现有数据不支持的人群和场景。
- [ ] T20：制定用途相关风险阈值并在校准集冻结；未验证的自报置信度不得控制自动放行。

第三阶段门槛：在锁定测试上公布实际表现，包含失败和弃答；结果不足时允许结论为“仅适合辅助人工”。

## 第四阶段：调校闭环（独立准入）

- [ ] T21：固定曲线/全局＋分区/生成式候选，统一预算与目标；保持未调整对照。
- [ ] T22：建立风格达成和内容保真双门；强迁移但重画细节、保真但未迁移均判不达标。
- [ ] T23：比较固定策略、模型选候选、模型诊断参数、带独立反馈四种策略；同样预算下验证引导独立收益。
- [ ] T24：保存每轮操作与裁决，实施停止/回退；不以事后挑选最好结果替代自动成功率。
- [ ] T25：发布收益、误放行、严重退化、耗时和成本，并列出不能自动处理的情况。

第四阶段门槛：独立盲评证明收益且风险满足预定用途要求；否则不部署自动调校，不把成功演示写成普遍能力。
